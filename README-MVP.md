# ForHuman Academy – MVP-Prototyp

## Start
Node.js 20+ installieren. Dann `npm install`, `npm run dev`; Produktions-Build mit `npm run build`.

## Vorhanden
Responsive Oberfläche, Stationskatalog mit ungeprüften SOP-Entwürfen, Filialfilter Halle/Leuna, Aufgaben-Checkliste mit localStorage, GGM-Wissenstest.

## Noch nicht vorhanden
Backend, Nutzerkonten, rollenbasierte Zugriffe, Cloud-Synchronisation, echte Bild-/Video-Uploads, tatsächliche Videos, SOP-Editor, vollständige arabische Übersetzung, praktische Freigaben, HACCP-Auditlog, PWA-Offlinefähigkeit und STRATO-Deployment.

**Nicht für den Echtbetrieb:** Gerätemodell, Originalhandbücher und Rezepte müssen vor Freigabe geprüft werden. Keine echten Daten oder Geheimnisse in diesem derzeit öffentlichen Repository hinterlegen. Siehe Issue #1.
